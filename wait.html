1. In a repo, add this file as index.html. Settings → Pages → deploy from main / root.
2. In the sheet: Share → General access → Anyone with the link → Viewer. Each refresh of the page then pulls the newest rows.
3. If the chart shows a load error, use File → Share → Publish to web, pick the Health Log tab, choose CSV, and paste that link into the box above (it's the most reliable cross-site source). You can also pass it via URL: ?src=….
